The desktop app can now connect to remote nuncio servers: a native Server menu with saved profiles, one-click Connect from the Remote access settings for tailnet devices running nuncio, automatic fallback to the local daemon when a remote stops responding, and the in-session terminal now opens the remote machine's shell (not the local one) when connected to a remote server.
